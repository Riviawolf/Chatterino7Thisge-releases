# Chatterino7Thisge Releases

Downloads for Chatterino7Thisge, a Chatterino chat client with
[Thisge](https://thisge.app) custom emote and name paint support built in,
alongside 7TV, BetterTTV, and FrankerFaceZ.

## Download

[Get the latest build from Releases](../../releases/latest)

- Installer (recommended): installs to its own folder and can update itself
  automatically.
- Portable: no installation, keeps its settings inside its own folder.

Windows may warn about an "unknown publisher" because the build is not code
signed yet. Click "More info", then "Run anyway".

## About

Chatterino7Thisge is based on
[Chatterino7](https://github.com/SevenTV/chatterino7) 7.5.5 by 7TV, itself a
fork of [Chatterino2](https://github.com/Chatterino/chatterino2). All three are

or Amazon.

For everything about the platform, visit [thisge.app](https://thisge.app).
